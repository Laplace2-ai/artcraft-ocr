# ArtCraft OCR 1.0.0

首个公开版本。

**下载**：`ArtCraftOCR-1.0.0-win64.zip`（101.8MB）——解压到任意位置，双击 `ArtCraftOCR.exe`。

SHA-256 见 `SHA256SUMS.txt`。

## 它能做什么

从图片里读出文字，写进 PhotoCraft 变成真正的文字图层。全程在本机完成：不需要账号、不上传、不联网。

- 支持中文简体、中文繁体、英文识别。
- 写入之前可以随便改：空行分一段，`+` / `×` 加减段落，每段的颜色和字号单独可调。
- 两种写入方式：**点文字**（一行一层，位置与字号按原图）或 **区域文字**（一段一个文本框）。
- 简繁是同一个按钮来回切，本地、即时。
- 整份结果可导出 JSON，拿到别处改（或翻译），再导入回来——翻译推荐走这条路。包里不带机器翻译：
  实测的 143M 模型会编造细节、翻错日期。

## 运行要求

- Windows 10 / 11，64 位。Python 运行时已包含在包里，不需要另外安装。
- WebView2 运行时（Windows 11 自带；Windows 10 随 Edge 安装）。
- 写入需要 PhotoCraft；识别、修改、导出不需要。

## 首次使用

1. **文件 → 设置…** → **选择 photocraft.exe…**
2. **在程序目录生成 photocraft_OCR.bat**
3. 用这个 bat 启动 PhotoCraft，再回到本程序写入。

直接双击 `photocraft.exe` 打开的那一份没有控制口，任何程序都写不进去。脚本就是为此存在的。

## 已知限制

- 大图上的短文本（一两个字）可能识别不出，裁紧一些可以救回来。
- 字号假定 PhotoCraft 文档在 100% 缩放。
- 窗口位置由系统决定。
- 目前只有 PhotoCraft 有适配器；FilmCraft、VectorCraft 在计划中。
